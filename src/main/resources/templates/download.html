Komm Server

Channels, messages, voice rooms and permissions, all on hardware you control. Optional: most people never touch this.

Database and media server are built in, and the server sets itself up: on its first start it gets its certificate, comes up on HTTPS and points voice at the right address. Run it as an OS service on Windows or Linux, or in Docker.

  1. 1

    Create the installation

    Create an account, then create an installation right from the Komm client: name it, pick your ports and, if you have one, a public address such as a domain. Its card shows a one-time verification code.

  2. 2

    Install with your code

    Pick how you want to run it below and give it the verification code.

  3. 3

    It sets itself up

    It activates itself with the hub and serves HTTPS on your ports from the very first start, with no restart and no certificate to buy. Update later with kommserver update or docker compose pull && docker compose up -d.

Good to know

Ports
Friends joining over the internet need your server port, plus 7881 (TCP) and 7882 (UDP) for voice, to be reachable through your router or firewall.
Home router
Voice works behind a home router: the server advertises the address the hub gives players for it, and follows it if your IP changes.
No installer
Prefer to run things yourself? Grab the plain server JAR, put your verification code into data/setup-token.txt (or set KOMM_SETUP_TOKEN) in the folder you run it from, and start it with Java 21. It activates itself on that first start, but does not update itself.

Komm Hub

Your own accounts and your own network. Most people just use the official hub at kommvoice.com.

The directory that manages accounts, friends and direct messages, and acts as the certificate authority every server registers with. Run your own and you have a fully independent Komm network.
