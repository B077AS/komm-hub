Host it yourself

Two separate, optional pieces - host one, both, or neither. Most people never touch this section.

Komm Server

Channels, messages, voice rooms and permissions, all on hardware you control. Database and media server are embedded - the launcher installs the rest as a proper OS service, not a script you babysit.

1 Create an account, then create an installation right from the Komm client - name it and pick your ports.
2 Run the Windows installer, or unpack the Linux package and run sudo ./install.sh. The launcher registers it as a Windows Service or systemd unit.
3 Hand it the one-time verification code from the installation's card. It fetches its certificate, verifies with the hub and comes online.
Windows Linux (tar.gz)
Prefer to run things yourself? Grab the plain server JAR instead - no verification code built in, drop your own into a setup-token.txt and run it with Java 21.

Komm Hub

The directory that manages accounts, friends and direct messages, and acts as the certificate authority every server registers with. Most people just use the official hub at kommvoice.com - this is for the ones who'd rather not.
